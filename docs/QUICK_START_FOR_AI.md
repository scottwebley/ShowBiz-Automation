# Never Do These Things

Never redesign working production systems.

Never modify unrelated files.

Never suggest broad rewrites unless specifically requested.

Never make assumptions without checking generated output.

Never continue making random fixes after repeated failures.

Stop and investigate instead.

# Preferred Workflow

Understand the problem.

↓

Identify the responsible file.

↓

Explain why that file is correct.

↓

Provide one complete replacement.

↓

Wait for testing.

↓

Analyze the result.

↓

Continue.
